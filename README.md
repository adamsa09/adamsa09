## Projects

### Robotic Dog
A proof-of-concept quadruped robot with **3 DoF per leg**.
- **C++** on an ESP32 for real-time motor control
- Full inverse kinematics for foot coordinate resolution
- Linear interpolation for trotting gait smoothing
- Fully modeled in CAD, manufactured with 3D printing & outsourced PCBs

### Sun-Tracking Solar Panel
A solar-powered weather station that autonomously orients itself toward the sun.
- **C++** on an ESP32
- Designed in CAD, 3D printed housing

### Alkalac — *2nd Place, Provincial Engineering Competition & finalist for Hydro-Québec science fair*
A fully autonomous system that neutralizes acidic bodies of water.
- Scalable, minimal human intervention
- Clean data dashboard for monitoring
- **Won second place at Odyssée de l'Objet**
- **Finalist in the Hydro-Québec science fair (ongoing)**
